# Git в VS Code и в терминале

## Что удобно в VS Code
1. Панель Source Control (Ctrl+Shift+G): видно все изменённые файлы, индексирование одним кликом по «+».
2. Встроенный diff «рядом»: изменения в строке подсвечиваются, не нужно читать вывод `git diff`.
3. GitLens: inline blame — автор и коммит для текущей строки прямо в редакторе.

## Что неудобно
1. Не видно, какие именно команды Git выполняются под капотом; при ошибке (например, отсутствии upstream) сообщение менее понятное, чем в терминале.

## Дополнение
После установки VS Code панель Source Control показывает изменённые файлы в разделе Changes, а клик по файлу открывает diff «было/стало» рядом.
