# Цели на семестр

1. Настроить собственный сервер на Ubuntu Server: SSH по ключу, UFW, Nginx с HTTPS — и описать конфигурацию так, чтобы её можно было восстановить за 10 минут.
2. Контейнеризировать учебное приложение (Docker, Docker Compose) и публиковать его через обратный прокси без открытых портов наружу.
3. Вести репозиторий по GitHub Flow: ветки, Pull Request, Conventional Commits, чистая история без WIP-коммитов.
